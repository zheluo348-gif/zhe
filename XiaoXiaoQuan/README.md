# 小小圈 iPhone 原生开发版

当前版本为 **0.4.1（6）**。使用SwiftUI，最低iOS 17，无第三方Swift包。

完整的功能范围、编译、模拟器/真机运行、规则检查、UI测试与AI接入状态，见仓库根目录的 [运行说明](../README.md)。

打开本目录的 `XiaoXiaoQuan.xcodeproj`，选择 `XiaoXiaoQuan` scheme 和 iPhone 模拟器即可运行。真机使用自己的开发团队签名。

源码和资源保存在本目录中；个人数据、设备备份、编译结果、签名证书及密钥不会随仓库提交。当前仍为本机体验版，真实AI、付费和双人联网聊天尚未接入。
